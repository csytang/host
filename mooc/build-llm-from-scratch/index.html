    ONLINE COURSE / 中文授课

    Build a Large Language Model from Scratch

    从零构建大型语言模型

    本课程以 Python 和 PyTorch 为主要工具，从文本分词、Embedding、注意力机制和 Transformer 开始，逐步实现 GPT 模型，并完成基础预训练。适合希望通过动手编程理解大语言模型工作原理的学习者。

    Udemy 课程入口 ↗ 查看课程大纲 ↓

    课程尚未提供正式的 Udemy 直达链接；当前按钮通往 Udemy 首页。

    V1 第一版 9 教学模块 56 个课节 Python · PyTorch
    学习路线Text→Tokens & Embeddings→Attention→GPT→Pretraining
